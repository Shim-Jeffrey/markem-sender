# 마켐 프린터 데이터 전송 — 간단 사용설명서 (v0.5.1)

대상 장비: SmartDate X40 / X45 계열(TTO). 연결: 이더넷, 포트 21000(고정).

## 1. 준비

- 설치: `MarkemSender_Setup_0.5.1.exe` 실행 → 확인 → 끝 (관리자 권한 불필요)
- 네트워크: 노트북과 프린터 모두 고정 IP, 같은 대역
- 프린터 이미지(라벨): 입력 필드 이름을 **text1, text2, text3 …** 순서로 만들어 둔다 (약속)
- 처음 실행: 타스코 마스터 계정 생성 → 마스터가 작업자·관리자 계정 생성
- 장비 없이 연습: `UI_보기_시뮬레이터포함.bat` 실행 → 장비 IP에 `127.0.0.1:21000`

## 전체 화면 잠금

- 실행하면 전체 화면으로 열리고, Windows 화면으로 나갈 수 없음(창 닫기·Alt+F4도 종료 확인으로 연결)
- 종료: 오른쪽 위 [프로그램 종료] → 마스터 아이디·비밀번호 확인 → 종료 (종료 기록 저장)
- 장비와 통신 중에는 종료 불가
- 한계: Ctrl+Alt+Del, Windows 키 등 운영체제 기능은 프로그램이 막지 못함(필요 시 Windows 키오스크 모드 설정)
- 시험용 일반 창 실행: `UI_보기.bat` 또는 `python app.py --window`

## 2. 사람과 역할

| 역할 | 하는 일 |
|---|---|
| 작업자(1차) | 작업 선택, 메세지 입력, [데이터 전송] 요청 |
| 관리자(2차) | 같은 작업·메세지를 입력해 확인, 전송 후 [인쇄 시작]·[정지] |
| 마스터 | 계정 관리, 기록 조회, 관리자 역할 겸임 |

- 같은 건에서 작업자와 관리자는 다른 사람
- 작업자 입력은 요청 후 10분 안에 관리자가 확인

## 3. 전송 흐름

1. 로그인 팝업에 아이디·비밀번호 입력 (모두 3·2·1 카운트 뒤 팝업이 스르르 닫힘) → 장비 IP 입력 → [연결] (초록 불 확인)
2. ① 작업: [프린터에서 불러오기] → 목록에서 선택 (이름 직접 입력 없음)
3. ② 보내는 메세지: 입력 → [추가] (추가한 순서대로 메세지 1, 2, 3 … 자동 번호)
4. [데이터 전송] → 자동 로그아웃
5. 관리자 로그인 → 같은 작업 선택, 같은 메세지를 같은 순서로 입력 (붙여넣기 불가) → [확인 및 전송]
6. 두 입력이 같으면 프린터로 전송 → 프린터 값 되읽기 → 결과 창
7. 결과 창에서 [인쇄 시작] 또는 [정지] 선택, 보낸 데이터와 프린터가 받은 메세지 확인 → [닫기]

- 메세지 1 → text1, 메세지 2 → text2 … 순서로 프린터에 들어감 (필드이름은 화면에 나오지 않음)
- 값이 다르면 관리자만 다시 입력 (3회 불일치 시 작업자부터 다시)
- [인쇄 시작]은 되읽기가 모두 초록일 때만 누를 수 있음, [정지]는 항상 가능
- 한 번 보낸 메세지는 새로 보내기 전까지 계속 같은 내용으로 인쇄됨(가변 아님)
- 정지 뒤 다시 [인쇄 시작]: 프린터를 준비(Ready) 상태로 되돌린 뒤 시작(데이터 다시 전송 불필요)

## 4. 결과 표시

| 표시 | 뜻 |
|---|---|
| 초록 | 프린터가 메세지를 정상적으로 받음 |
| 노랑 | 확인 필요 (프린터에서 메세지 칸을 못 찾음, 대소문자·공백 차이, 되읽기 실패) |
| 빨강 | 전송되지 않음 (사유 표시): 불일치 3회·만료·장비 오류·연결 끊김 |

- 노랑 "찾지 못함": 프린터 이미지의 필드 이름이 text1, text2 … 와 맞는지 확인
- 되읽기로 확인하는 것은 프린터에 들어간 값. 실제 인쇄 결과 확인은 아님

## 5. 조회와 설정

- 프린터 메세지 조회: 현재 작업에 들어 있는 메세지를 번호 순서대로 확인
- 설정 조회: 설정 이름으로 현재 값 확인
- 설정 변경: 작업자 요청 → 관리자 확인(이중 입력) → 변경 후 되읽기. 인쇄 중에는 반영 안 됨

## 6. 연결 옵션 (모르면 기본값)

| 옵션 | 설명 |
|---|---|
| 패킷 문자 | 메시지 시작·끝 표시 방식. 프린터가 STX/ETX면 두 번째 선택 |
| 오류 검사 숫자(체크필드) | 프린터에서 켠 경우에만 체크 |
| 답장에 성공 여부 붙임 | 프린터 설정과 같게. 모르면 켬 |
| 모든 글자 지원(유니코드) | 프린터가 영문·숫자만이면 끔 |

## 7. 문제가 생기면

| 증상 | 확인 |
|---|---|
| 연결 안 됨 | 프린터 IP·같은 대역·케이블, 프린터의 NGPCL 통신 설정 |
| 답이 없음·시간 초과 | 연결 옵션이 프린터 설정과 같은지 |
| 작업 불러오기 실패 | 프린터에서 작업을 먼저 선택, 연결 상태 |
| 노랑(메세지 칸 못 찾음) | 프린터 이미지 필드 이름 text1, text2 … |
| 빨간 창 | 사유 문구 확인 → 작업자부터 다시 입력 |
| 로그아웃 안 됨 | 장비와 통신 중, 끝난 뒤 다시 |

- 통신 로그(화면 아래): 주고받은 내용. 문의 시 함께 전달

## 8. 기록

- 마스터 → 기록 탭: 로그인·계정 변경·작업 결과(1차·2차·데이터·수신 확인)·인쇄 시작/정지
- [CSV 내보내기]로 엑셀 저장, [무결성 확인]으로 변조 여부 확인
- 저장 위치: `C:\ProgramData\TASCO\MarkemSender\` (백업 필요)
- 통신 기록 파일: 같은 폴더의 `comm_날짜.log` (프린터와 주고받은 내용, 문제 분석용)

## 9. 알려진 한계 (실장비 시험 필요)

- 프린터의 작업 목록 조회 명령이 없어(NGPCL v25), [프린터에서 불러오기]는 현재 작업만 불러오고 이전에 쓴 작업은 이 PC에 기억해 목록에 보여 줌
- 인쇄 시작(`~ST|06|`)·정지(`~ST|11|`) 상태 코드의 실제 동작 확인 필요
- 프린터 메세지 조회(`~FR`) 응답 형식·설정 이름은 장비별 확인 필요
