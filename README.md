# 마켐이마지 프린터 데이터 전송 (초안 v0.2)

노트북에서 이더넷으로 마켐이마지 장비에 작업·필드 데이터를 보내는 Windows 프로그램. 장비 종류별 화면: **TTO**(NGPCL 구현) / **CIJ**(규격 확인 전, 자리만).
작업자(1차)와 관리자(2차)가 **같은 내용을 입력해야만** 장비로 전송됩니다.

## 실행

- 장비 없이 시험: `UI_보기_시뮬레이터포함.bat` 더블클릭 (가짜 장비 + 화면). 장비 IP에 `127.0.0.1:21000`
- 실제 장비: 장비 IP만 입력(포트는 항상 21000). 노트북과 장비 모두 고정 IP, 같은 대역으로 설정
- 필요: Python 3.13, Pillow (`pip install pillow`)
- 시험: `python -m unittest discover -s tests` (53개)

## 설치 파일

- 만들기: `pip install pyinstaller pillow` 후 `python installer/build.py` → `dist\MarkemSender_Setup_<버전>.exe` (약 31MB)
- 설치: Setup.exe 더블클릭 → 확인 → 끝. **관리자 권한 불필요**, 현재 Windows 사용자 폴더(`%LOCALAPPDATA%\Programs\TASCO\MarkemSender`)에 설치, 시작 메뉴·바탕화면 바로가기와 "앱 및 기능" 제거 항목 생성
- 일괄 설치: `MarkemSender_Setup_<버전>.exe /Q` (대화상자 없음)
- 제거: "앱 및 기능"에서 제거. 계정·기록 데이터(`C:\ProgramData\TASCO\MarkemSender`)는 지우지 않고 남김
- 업데이트: 새 Setup.exe를 실행하면 프로그램 파일만 바뀌고 계정·기록은 그대로
- 코드 서명이 없어 처음 실행 때 Windows SmartScreen 경고가 뜰 수 있음("추가 정보 → 실행")

## 사용 흐름

1. 처음 실행: **타스코 마스터** 계정 만들기. 타스코 마스터가 계정 추가에서 **거래처 마스터(1개)**, 작업자, 관리자를 만든다
2. 1차 작업자 로그인 → 장비 연결 → 작업 이름·필드 입력 → **확인 요청** (로그아웃됨, 입력은 메모리에만 보관)
3. 2차 관리자 로그인 → 확인 입력 화면이 자동으로 열림 → 1차 값을 보지 않고 같은 내용을 직접 입력(붙여넣기 불가)
   - 일치 → 장비 전송 → 결과 기록
   - 불일치 → "n/3회" 안내, 2차만 다시 입력 (1차 입력 유지)
   - **3회 불일치 → 1차 입력 폐기, 1차 작업자부터 다시**
4. 1차 입력은 10분 안에 확인되지 않으면 폐기(기록됨)

## 계정과 기록

- 역할: 1차 작업자 / 2차 관리자 / 마스터(타스코) / 마스터(거래처). 마스터는 전송 화면(TTO/CIJ)·계정 관리·기록을 모두 보고, **2차 확인도 할 수 있음**(TTO 탭의 [2차 확인 입력]). 1차 입력은 작업자만
- 타스코 마스터가 상위: 거래처 마스터를 만들고 지우고 초기화할 수 있음. 거래처 마스터는 작업자·관리자만 관리하고 타스코 마스터는 건드릴 수 없음
- 비밀번호 5회 실패 시 잠김(작업자·관리자는 마스터가 해제, 마스터는 15분 뒤 자동 해제), 미사용 10분이면 자동 로그아웃
- 기록(변조 감지 해시 체인): 로그인, **마스터가 바꾼 모든 내역(실행자·소속·이전/이후)**, 권한 없는 시도, **작업 성공/실패 + 1차 누구·2차 누구**
- 기록 화면에서 종류별 보기, 무결성 확인, **CSV 내보내기**(작업 로그 / 계정 변경 / 로그인)
- 저장 위치: `C:\ProgramData\TASCO\MarkemSender\data.db` (이 PC 안에만 저장, 백업 필요)
- 개발 모드(`MARKEM_DEV=1`)에서만 저장 폴더를 환경변수로 바꿀 수 있음

## 확인 필요

- 체크필드: 설계서 예제 합계(4760)와 계산값(4764)이 달라 설계서 오류인지 확인. 기본은 끔
- 한글 필드값: 장비의 문자 설정이 유니코드여야 함. 16비트 바이트 순서(리틀엔디언 가정)는 미확인
- 장비 쪽 설정: 포트 기능 NGPCL, 문자셋, 체크필드, 상태 필드를 화면 옵션과 같게 맞춰야 함. 설정 위치는 서비스 매뉴얼 85쪽(Communication Settings)으로 추정, 아직 읽지 못함
- 필드 이름: 이미지 디자인에서 사용자 입력(User Input) 소스로 만든 필드만 갱신 가능
- 인쇄 신호 단독은 이중 입력 없이 작업자가 보낼 수 있음(임시 기본값)
- 마스터 권한 관계·기록 조회 범위 등 설계안의 임시 기본값
- CIJ(9xxx): 통신 규격 문서 필요
- 설치 파일(exe)·설치 폴더 접근 권한 제한은 아직 없음
