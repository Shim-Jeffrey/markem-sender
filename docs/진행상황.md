### 지금 상태

- main 브랜치, 작업 트리 깨끗, GitHub(비공개 Shim-Jeffrey/markem-sender)와 같음
- 시험 54개 통과(`python -m unittest discover -s tests`), 시뮬레이터 화면 흐름 통과
- 설치 파일: `python installer/build.py` → `dist\MarkemSender_Setup_0.2.0.exe` (dist는 저장소에 없음, 다른 PC에서는 빌드 필요)

### 된 것

- NGPCL(TCP 21000) 통신, 시뮬레이터, TTO/CIJ 탭 화면(TASCO 남색)
- 로그인·역할: 1차 작업자 / 2차 관리자 / 마스터(타스코 상위·거래처 1개)
- 이중 입력 전송: 1차 메모리 보관 → 2차 같은 입력 일치 시에만 전송, 2차 3회 불일치 시 1차부터, 10분 만료, 1회용 승인표
- 마스터도 2차 확인 가능(1차는 작업자만), 마스터 화면에 전송 탭
- 기록(해시 체인): 로그인·마스터 변경 내역(실행자·소속·이전/이후)·권한 없는 시도·작업 성공/실패(1차·2차·소속·데이터), CSV 내보내기
- 마스터가 24시간 안에 만들거나 초기화한 1차 계정을 직접 승인하면 [주의] 표시(막지 않음, 확정)
- 설치 파일(IExpress Setup.exe, 관리자 권한 불필요, /Q 일괄 설치), 보안 검토 3회 반영

### 결정 대기 (대표님)

1. 소속이 다른 승인(타스코↔거래처) 허용 여부 — 고객사 GMP 기준 확인
2. 인쇄 신호 단독을 이중 입력 없이 둘지
3. 설계안(`docs/설계-이중입력.md`)의 나머지 임시 기본값

### 확인 필요 (자료·장비)

- 반전·180° 회전: NGPCL 문서에 설정 이름 목록 없음 → 서비스 매뉴얼 Settings(263쪽)·Menu Tree(281쪽) 필요. 이름을 알면 `~SC`(설정 변경)로 이중 입력 기능 추가 가능
- 장비 통신 설정 위치: 서비스 매뉴얼 85쪽(Communication Settings) — 기본 IP·NGPCL 켜는 법
- 실제 장비 시험: 체크필드(설계서 예제 4760 vs 계산 4764), 유니코드 바이트 순서, 필드 이름(User Input 소스)
- CIJ(9xxx) 통신 규격 문서
- 코드 서명 인증서(SmartScreen 경고), 데이터 폴더 권한 제한

### 다음에 할 첫 행동

```bash
git clone https://github.com/Shim-Jeffrey/markem-sender.git   # 다른 PC면
cd markem-sender && pip install pillow pyinstaller && python -m unittest discover -s tests
```

그다음: 매뉴얼 Settings 쪽(263쪽 부근) PDF를 받아 반전·회전 설정 이름 확인 → 화면에 "방향 설정" 추가 여부 결정
