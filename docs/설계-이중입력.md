# 설계안: 로그인 + 이중 입력 전송 (2026-11-03, 초안)

## 확정

- 설치형 Windows 프로그램, **PC 1대**에서 작업자와 관리자가 번갈아 로그인
- 역할 3개: 1차 작업자 / 2차 관리자 / 마스터
- 두 사람이 입력한 **장비로 나갈 메시지가 같을 때만** 전송, 다르면 알림 후 작업자가 처음부터 재입력
- 마스터는 계정 생성·삭제 가능

## 임시 기본값 (확인 필요)

| 항목 | 임시 기본값 | 확인 |
|---|---|---|
| 마스터가 관리자 승인도 가능한가 | 불가(계정 관리만) | 필요 |
| 이중 입력 대상 | 작업 선택 · 필드 갱신 · 갱신 후 인쇄 (상태 조회는 로그인만) | 필요 |
| 인쇄 신호 단독 | 로그인만 (이중 입력 없음) | 필요 |
| 작업자 입력 만료 | 10분 | 필요 |
| 불일치 연속 횟수 제한 | 3회 → 마스터 확인 | 필요 |
| 고객사 GMP(전자기록·서명) 준수 | 이번 범위 밖, 감사 기록으로 대비 | 필요 |

## 흐름

1. 작업자 로그인 → 작업·필드 입력 → **[관리자 확인 요청]** (전송 버튼 없음)
2. 작업자 입력은 **메모리에만** 보관(디스크 저장 없음), 화면은 잠금
3. 관리자 로그인 → 같은 항목을 **작업자 값을 보지 못한 채** 직접 입력(붙여넣기 금지)
4. 비교: 두 입력으로 만든 NGPCL 메시지 문자열 전체
   - 일치 → 관리자 화면에서 **[전송]** → 장비 전송 → 기록
   - 불일치 → 알림(틀린 **필드 이름만** 표시, 값 비공개) → 두 입력 폐기 → 작업자 재입력
5. 만료·프로그램 종료·로그아웃 시 작업자 입력 폐기

```
대기 ─작업자 입력→ 확인대기 ─관리자 입력→ 비교 ┬ 일치 → 전송 → 기록 → 대기
                                              └ 불일치 → 폐기 → 대기(작업자 재입력)
```

## 규칙

- 한 건 안에서 작업자와 관리자는 **다른 계정**
- 전송 함수는 "일치 판정 통과" 객체 없이는 호출 불가(우회 경로 없음)
- 전송은 일치 판정 직후 한 번만, 재전송은 새 이중 입력

## 계정

- 저장: 로컬 SQLite(`%ProgramData%\TASCO\MarkemSender\`)
- 비밀번호: scrypt 해시(원문 저장 없음), 첫 로그인 때 변경 강제
- 로그인 실패 5회 → 잠금(마스터가 해제), 미사용 10분 → 자동 로그아웃
- 최초 실행: 마스터 생성 화면
- 삭제: 계정은 삭제하되 **기록은 유지**(이름·ID를 기록에 보관), 비활성화도 지원
- 마스터 비밀번호 분실: 복구 절차 별도 정의(확인 필요)

## 감사 기록

- **작업 로그**(건마다 1줄): `시각 / 결과 / 1차(작업자) 누구 / 2차(관리자) 누구 / 작업 내용`
  - 작업 성공 / 1차 누구 2차 누구
  - 작업 실패 / 1차 누구 2차 누구 + **실패 사유**
- 실패 사유 구분: 입력 불일치(틀린 필드명) · 장비 오류(응답 코드, 시간 초과, 연결 끊김) · 작업자 입력 만료 · 관리자 인증 실패
- 2차가 로그인하기 전에 끝난 건(작업자 취소·만료)은 2차 칸을 "없음"으로 기록
- 작업/필드 값은 전송 건에 한해 기록
- 별도 기록: 로그인 성공·실패·잠금, 계정 생성·삭제·비활성화
- 변조 감지: 기록마다 이전 기록의 해시를 포함(해시 체인)
- 로그인·실패·계정 변경도 기록

## 화면 변경

- 로그인 화면(역할별 진입)
- 작업자: 입력 화면 + [관리자 확인 요청]
- 관리자: 재입력 화면 + 일치 시 [전송]
- 마스터: 계정 관리(생성·삭제·비활성화·비밀번호 초기화), 기록 조회
- 상단에 현재 로그인 계정·역할 표시

## 한계

- 프로그램 안의 통제. 다른 도구로 장비에 직접 접속하는 것은 막지 못함(NGPCL은 장비당 1접속이라 프로그램이 접속을 유지하면 일부 완화)
- Windows 관리자의 DB 직접 수정은 막지 못하고 변조 감지만 가능

## 구현 순서

1. 계정·로그인·역할(마스터 생성, 계정 관리)
2. 이중 입력 흐름 + 불일치 처리 + 전송 차단 구조
3. 감사 기록(해시 체인)
4. 설치 파일(PyInstaller + Inno Setup)
5. 보안 검토(인증·권한 코드)
