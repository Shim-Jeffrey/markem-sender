# 마켐이마지 프린터 데이터 전송 (초안 v0.2)

노트북에서 이더넷으로 마켐이마지 장비에 작업·필드 데이터를 보내는 Windows 프로그램. 장비 종류별 화면: **TTO**(NGPCL 구현) / **CIJ**(규격 확인 전, 자리만).

## 실행

- 장비 없이 시험: 터미널 1에서 `python sim_printer.py` → 터미널 2에서 `python app.py` → 장비 IP에 `127.0.0.1:21000` 입력 후 연결
- 실제 장비: 장비 IP만 입력(포트는 항상 21000). 노트북과 장비 모두 고정 IP, 같은 대역으로 설정
- 필요: Python 3.13, Pillow (`pip install pillow`)

## 로그인과 계정 (v0.2, 1단계)

- 처음 실행하면 **마스터 계정 만들기** 화면이 뜹니다. 마스터는 계정을 만들고 지우는 관리자입니다
- 역할: 1차 작업자 / 2차 관리자 / 마스터. 마스터는 계정 관리·기록 화면만, 나머지는 장비 화면
- 새 계정은 임시 비밀번호로 만들고, 처음 로그인할 때 본인이 바꿉니다
- 비밀번호 5회 실패 시 잠김(마스터가 해제), 미사용 10분이면 자동 로그아웃
- 계정·기록 저장 위치: `C:\ProgramData\TASCO\MarkemSender\data.db` (이 PC 안에만 저장, 백업 필요)
- 아직 없음(2단계~): 작업자·관리자 이중 입력 일치 시에만 전송, 작업 성공/실패 로그와 CSV 내보내기
- 보안 검토 반영: 비밀번호 변경 실패도 횟수·잠금·기록, 기록 끝부분 삭제 감지, 기록 조회는 마스터만, 프로그램 중복 실행 방지, 저장 폴더는 환경변수로 바꿀 수 없음(개발 모드 `MARKEM_DEV=1`일 때만)
- 시험: `python -m unittest discover -s tests` (20개)

## 파일

| 파일 | 역할 |
|---|---|
| `ngpcl.py` | NGPCL 통신(패킷·체크필드·메시지 생성·응답 해석). 근거: NGPCL Users Guide v25 |
| `app.py` | 화면(TASCO 남색·흰색). 로그인 흐름, TTO/CIJ 탭 |
| `auth_ui.py` | 로그인·계정 관리·기록 화면 |
| `store.py` | 계정·기록 저장(SQLite, 비밀번호 해시, 해시 체인 기록) |
| `app_theme.py` | 색·카드 공통 |
| `sim_printer.py` | 가짜 마켐 장비(시험용) |
| `assets\` | TASCO 로고(브랜드가이드 파일 복사본) |

## TTO 화면에서 되는 것

연결/해제 · 작업 선택(~JS) · 필드 갱신(~JU) · 갱신 후 인쇄(~JU → ~PS 대기 → ~PG, 설계서 10장) · 인쇄 신호(~PG) · 상태·현재 작업·카운트 조회(~DR/~JR/~CR)

## 확인 필요 (실제 장비에서 검증)

- 체크필드: 설계서 예제 합계(4760)와 계산값(4764)이 달라 설계서 오류인지 확인. 기본은 끔
- 한글 필드값: 장비의 문자 설정이 유니코드여야 함. 16비트 바이트 순서(리틀엔디언 가정)는 미확인
- 장비 쪽 설정: 포트 기능 NGPCL, 문자셋, 체크필드, 상태 필드를 화면 옵션과 같게 맞춰야 함. 설정 위치는 서비스 매뉴얼 85쪽(Communication Settings)으로 추정, 아직 읽지 못함
- 필드 이름: 이미지 디자인에서 사용자 입력(User Input) 소스로 만든 필드만 갱신 가능
- CIJ(9xxx): 통신 규격 문서 필요
